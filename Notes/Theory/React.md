### What is react?
- React is a JavaScript library for building user interfaces.
- Created by facebook.
- it is known for its component-based structure, single-page applications (SPAs), and virtual DOM, enabling efficient UI updates and a smooth user experience.
```text
                  React Application
                       │
                       ↓
              ┌─────────────────┐
              │   Components    │
              │                 │
              │ Functional      │
              │ Class           │
              └────────┬────────┘
                       │
              ┌────────▼────────┐
              │ Props & State   │
              └────────┬────────┘
                       │
                       ↓
                 React Elements
                       │
                       ↓
                    JSX
                       │
                       ↓
              Virtual DOM / Tree
                       │
                       ↓
              Reconciliation
                       │
                       ↓
             Real DOM (Browser)
                       │
                       ↓
                    UI
```
